# utils/

**Qué va aquí:** **funciones puras** y reutilizables sin efectos secundarios: formateo de fechas y cantidades, cálculos de sostenibilidad (por ejemplo, huella de carbono total de un lote), validaciones.

**Reglas**
- Misma entrada → misma salida. Sin llamadas de red, sin React, sin estado.
- Cada función debe poder probarse con un test unitario simple.
